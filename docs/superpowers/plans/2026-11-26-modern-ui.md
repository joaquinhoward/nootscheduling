> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the tedious cell-by-cell test page with a modern two-column page: list inputs, Random, Examples,
inline errors, colored Gantt chart and step-by-step playback.

**Architecture:** New pure modules (list validation, examples, random generator, playback text) are tested with

**Tech Stack:** React 19, Vite, Vitest, plain CSS.

**Spec:** `docs/superpowers/specs/2026-11-26-modern-ui-design.md`

## Global Constraints

- Do not change `fcfs.js`, `roundRobin.js`, `metrics.js`. All 24 existing tests must still pass.
- Limits stay: 1–10 processes, Arrival whole ≥ 0, Burst whole ≥ 1, Quantum whole ≥ 1, every value ≤ 1000.
- No copying of algos.dcism.org's font or exact styling; system font stack.
- Branch `feat/modern-ui`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Lists with extra spaces, trailing commas, or mixed `0, 2  4,6` separators parse as 4 values. Tested in Task 1.
- Different counts in the two fields give one clear general error, not per-value noise. Tested in Task 1.
- Pressing Play while already at the last step restarts from step 0 instead of doing nothing. Checked in Task 4.
- Changing input while playback is running stops the timer (no state updates on a cleared output). Checked in Task 4.
- Random and every Example always produce valid input. Tested in Task 2.

### Task 1: List input validation

**Files:**
- Modify: `src/algorithms/validation.js`
- Test: `src/algorithms/validation.test.js` (append)

**Interfaces:**
- Produces: `splitList(text: string) → string[]` (split on `/[\s,]+/`, empty tokens dropped)
- Produces: `validateLists(arrivalText: string, burstText: string) → { processes: {pid, arrival, burst}[] | null, errors: { arrival: string[], burst: string[], general: string[] } }`
  - Reuses `checkField` with label `Arrival time #<i>` / `Burst time #<i>` (1-based) and below-min messages
    `Arrival time #<i> cannot be negative.` / `Burst time #<i> must be at least 1.`
  - Empty field: `Enter at least one arrival time.` / `Enter at least one burst time.` (in that field's array)
  - Counts differ (both non-empty): general `You entered <a> arrival time(s) but <b> burst time(s).` — singular
    when the count is 1. Per-value checks still run.
  - More than 10 values in either field: general `Enter between 1 and 10 processes.`
  - `processes` is `null` when any array is non-empty.

- [ ] **Step 1: Write the failing tests** (append to `validation.test.js`)

```js
import { splitList, validateLists } from './validation.js'

describe('splitList', () => {
  it('splits on spaces and commas, ignoring extras', () => {
    expect(splitList(' 0, 2  4,6, ')).toEqual(['0', '2', '4', '6'])
    expect(splitList('   ')).toEqual([])
  })
})

describe('validateLists', () => {
  it('pairs the lists into processes', () => {
    expect(validateLists('0 2', '5, 3')).toEqual({
      processes: [
        { pid: 1, arrival: 0, burst: 5 },
        { pid: 2, arrival: 2, burst: 3 },
      ],
      errors: { arrival: [], burst: [], general: [] },
    })
  })

  it('asks for both lists when empty', () => {
    expect(validateLists('', ' ').errors).toEqual({
      arrival: ['Enter at least one arrival time.'],
      burst: ['Enter at least one burst time.'],
      general: [],
    })
  })

  it('reports mismatched counts once', () => {
    const { processes, errors } = validateLists('0 1 2 3', '5 3 1')
    expect(processes).toBeNull()
    expect(errors.general).toEqual(['You entered 4 arrival times but 3 burst times.'])
    expect(validateLists('0', '1 2').errors.general).toEqual(['You entered 1 arrival time but 2 burst times.'])
  })

  it('reports each bad value with its position', () => {
    expect(validateLists('0 -1 x', '0 2.5 1001').errors).toEqual({
      arrival: ['Arrival time #2 cannot be negative.', 'Arrival time #3 must be a whole number.'],
      burst: [
        'Burst time #1 must be at least 1.',
        'Burst time #2 must be a whole number.',
        'Burst time #3 must be at most 1000.',
      ],
      general: [],
    })
  })

  it('rejects more than 10 processes', () => {
    const eleven = Array(11).fill('1').join(' ')
    expect(validateLists(eleven, eleven).errors.general).toEqual(['Enter between 1 and 10 processes.'])
  })
})
```

import { describeStep, timeAtStep } from './playback.js'
